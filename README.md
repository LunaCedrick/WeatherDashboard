# Weather Dashboard

A weather-reactive dashboard that changes its sky background based on real OpenWeatherMap conditions.

## Status

Active development. Project structure is prepared; feature layers will be built one session at a time.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- OpenWeatherMap API
- Google Fonts: Poppins and Inter

## Local Setup

1. Add an OpenWeatherMap API key to `js/config.js`.
2. Open `index.html` in a browser.

## Development Workflow

Builds follow the project skill sequence:

1. setup
2. api
3. background
4. ui
5. app
6. responsive
7. performance
